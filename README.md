
# 🔍 Python Nmap Scanner

A simple Python tool that uses Nmap to scan hosts and services in a given subnet.

## ✨ Features
- Scan single IP or entire subnet
- Detect open ports and running services
- Save results for later analysis

## 📦 Requirements
- Python 3.x
- [Nmap](https://nmap.org/) installed on your system
- python-nmap library

Install dependencies:
```bash
pip install -r requirements.txt
